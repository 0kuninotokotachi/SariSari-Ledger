# Documentation

Specifications, requirements, and feature designs for SariSari-Ledger live here, per `CLAUDE.md`'s agent guidelines. Update the relevant file whenever a feature is added or changed.

## Features

- [Utang Management](features/utang-management.md) — customer credit (utang) tracking: adding customers, recording loans/repayments, and browsing customer history.
- [Customer Search & Pinning](features/customer-search-and-pinning.md) — searching, filtering, and sorting the customer list, and pinning favorite customers to the dashboard.
